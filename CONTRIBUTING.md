# Contributing to Rhythm Trainer

Rhythm Trainer is proprietary software owned by Proximity Software Factory LLC. This document defines
the terms under which contributions are accepted.

## Contributor IP Assignment

By submitting any contribution to this project — including but not limited to
code, documentation, architecture designs, prompt templates, test fixtures,
configuration, or any other materials — you agree to the following:

1. **Assignment of Rights.** You irrevocably assign to Proximity Software Factory LLC all right,
   title, and interest in and to your contribution, including all intellectual
   property rights (copyright, patent, trade secret, and any other rights)
   worldwide.

2. **Original Work.** You represent that your contribution is your original work
   and that you have the legal right to assign it. If any part of your
   contribution is subject to a third-party license, you must disclose this
   before submitting.

3. **No Encumbrances.** Your contribution is free of any liens, claims, or
   encumbrances. You have not and will not grant any rights in your contribution
   to any third party that conflict with this assignment.

4. **Moral Rights Waiver.** To the extent permitted by law, you waive any moral
   rights in your contribution.

5. **Assistance.** You agree to execute any documents and take any actions
   reasonably requested by Proximity Software Factory LLC to perfect, protect, or enforce the
   rights assigned herein.

## AI-Assisted Contributions

Contributions generated with the assistance of AI tools (including but not
limited to Claude, GPT, Copilot, or similar) are accepted under the same
assignment terms above. The contributor submitting AI-assisted work is
responsible for:

- Reviewing all AI-generated output for correctness and security
- Ensuring no third-party proprietary code is included
- Disclosing which portions were AI-assisted if requested

## Confidentiality

All contributors, whether human or operating AI tools on behalf of the project,
must treat the following as confidential:

- Source code and architecture
- Prompt templates and scoring logic
- API schemas and internal protocols
- Business logic and processing pipelines
- Unreleased features and roadmap

Do not share any of the above outside the project without written permission
from Proximity Software Factory LLC.

## Code Standards

When code contributions begin:

- Every source file must include the copyright header from `COPYRIGHT_HEADER`
- Follow existing code style and conventions
- Include tests for new functionality
- Do not introduce third-party dependencies without approval

## How to Contribute

This is a private project. If you have been granted access to contribute:

1. Work on a branch, not main
2. Ensure all tests pass before submitting
3. Submit a pull request with a clear description
4. Your PR constitutes acceptance of the terms in this document

## Questions

Contact Proximity Software Factory LLC with any questions about these terms.
